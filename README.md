## Featured project

### [SIN GUARDAR](https://truevexine.github.io/sin-guardar.html): narrative game in Java

A cosmic horror visual novel where your choices change the story *and* how the game looks.
22 decision nodes, 3 endings (one secret) and an **Erosion** system that alters the narration and visuals as it rises.
Built solo in Java 17 (started in Swing, finished in JavaFX) with Maven. *In development.*

[▶ Watch the gameplay](https://www.youtube.com/watch?v=x4OkNthPtdE) · [Read the case study](https://truevexine.github.io/sin-guardar.html)
